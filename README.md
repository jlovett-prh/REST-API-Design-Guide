# Penguin Random House UK REST API Design Guide

## About
This repository is a working adaptation of the [National Bank of Belgium REST API Design Guide](https://github.com/NationalBankBelgium/REST-API-Design-Guide), intended to develop a shared REST API standard for Penguin Random House UK (PRH UK).

Read the guide in [this repository's wiki](https://github.com/jlovett-prh/REST-API-Design-Guide/wiki/Home).

## Status and provenance

This is a draft for review and adaptation, not an approved PRH UK standard. The wiki adapts the NBB guide with PRH UK branding and illustrative addresses; its technical recommendations remain subject to PRH UK review.

The original guide and its history are preserved. This adaptation is maintained independently and does not imply endorsement by the National Bank of Belgium.

### Changes

- 19 October 2026: Rebranded the wiki for Penguin Random House UK (PRH UK), clarified draft status and updated illustrative addresses. Technical recommendations remain unchanged.

- 19 October 2026: Imported the NBB wiki with its history and updated this README to describe the PRH UK adaptation and link to its wiki. No technical guidance has been changed.
