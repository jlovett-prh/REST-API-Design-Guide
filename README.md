# PRH REST API Design Guide

## About
This repository is a working adaptation of the [National Bank of Belgium REST API Design Guide](https://github.com/NationalBankBelgium/REST-API-Design-Guide), intended to develop a shared REST API standard for PRH.

Read the guide in [this repository's wiki](https://github.com/jlovett-prh/REST-API-Design-Guide/wiki/Home).

## Status and provenance

This is a draft for review and adaptation, not an approved PRH standard. The wiki currently reproduces the NBB guide; PRH-specific requirements and examples will be developed here.

The original guide and its history are preserved. This adaptation is maintained independently and does not imply endorsement by the National Bank of Belgium.

### Changes

- 19 October 2026: Imported the NBB wiki with its history and updated this README to describe the PRH adaptation and link to its wiki. No technical guidance has been changed.
